## 0. 这份文档集是什么

Skill OS（个人 / 团队的 AI Skill 资产账本与治理控制台）的**全套设计文档**，覆盖需求 → 选型 → 排期 → 系统设计 → 跨平台约束，外加两份外部调研（一个 5532★ 同类项目的架构对比与踩坑史）。

**冻结意味着**：`FR-*` / `NFR-*` / `OUT-*` 编号、数据模型、接口契约、决策编号 `T1–T22` 均已定稿，代码可以按它逐条实现。**冻结不等于不可改** —— 但改要走 §4 的流程。

| 项 | 值 |
|---|---|
| 基线版本 | **BASELINE-1.0** |
| 冻结日期 | 2026-10-06 |
| 交付截止 | 2026-10-18（黑客松大赛） |
| 规模 | 6 份正式文档（`00`/`02`/`03`/`04`/`05`/`08`）+ 2 份调研记录（`06`/`07`）+ 1 份归档（`01`）+ 本索引，共约 5,450 行 |
| 权威源 | **`00-需求定稿.md`** —— 任何冲突以它为准 |

## 4. 冻结后的变更流程

冻结的意图是**让代码有个稳定的靶子**，不是锁住文档。要改就按这个顺序走：

```text
1. 判定性质
   ├─ 实现细节（文档没写到）      → 直接实现，回头补进 04
   ├─ 与文档冲突的实现            → 停，先问；不许"先写代码后补文档"
   └─ 需求 / 选型 / 数据模型变更  → 走 2
2. 先在 00-需求定稿.md 立或改编号（新需求 = 新 FR 号；废弃 = 移入 OUT-*）
3. 再改 02（若涉选型/决策，新增 T 编号）/ 04（设计）/ 05（平台）
4. 最后改 03（排期与预算）与 08（若涉定位）
5. 更新本文档 §6 的变更记录
```

**禁止**：跳过 `00` 直接改 `04` 并引用一个不存在的 `FR` 号 —— 这会让"编号 ↔ 实现"的可追溯性断掉，而它正是这套文档存在的主要理由。

**降级路径**（时间不够时，优先动这里）：
- 砍单项与降级路径见 `00` §8 与 `03` §3，**不要临时发明新的砍法**。
- 不可退让项（6 项）见 `00` §8 —— 包括**质量门禁的 `error` 级拦截**与**一键分发的删除守卫**。

## 5. 代码仓库结构对应

```text
SkillOS/
├── CODEBUDDY.md          # 编码代理项目规则（每次会话全文加载）—— 与本文档同为冻结版
├── docs/                 # ← 本目录：设计文档（SSOT for design）
│   ├── README.md         #   本文档
│   ├── 00 ~ 08           #   正式文档（见 §1）
│   └── refs/             #   外部证据快照
├── app/index.html        # 前端设计原型 + Design Tokens 唯一来源
├── skillos/              # D1 交付物：CLI / daemon / MCP 三模式共用一个包
│   ├── core/
│   │   ├── algorithm/    #   纯算法（云端可复用）：adapters / checks / drift / parse / similarity
│   │   └── fs/           #   仅本地：safe_path / scan / distribute / importer / version / upstream
│   ├── services/         #   编排层（事务边界）：sync / skill / cr / check / version / team / upstream / locking
│   ├── store/            #   持久化：models / db / index_repo
│   ├── api/              #   D3 云端后端：FastAPI + routes + ws_hub
│   ├── daemon/           #   本地常驻进程（出站连云端，无需公网 IP）
│   ├── mcp/              #   MCP Server（Agent 自管入口）
│   └── cli/              #   CLI 入口
├── web/                  # D2 交付物：Web 控制台（React + Vite，src/api/schema.d.ts 由 openapi-typescript 生成）
├── data/migrations/      # Alembic 迁移（表结构以迁移为准）
└── tests/                # pytest + vitest
```

**分层方向单向**：`入口(cli/mcp/daemon/api) → services → core / store`。`core` **不得** import `services` 或 `store`（详见 `CODEBUDDY.md` §3）。
