## 八、全局工程纪律（贯穿所有里程碑）

1. **提交粒度**：一个任务 = 1~2 个 commit，message `<type>(<scope>): <subject>`；每 commit 前该任务验收 GWT 对应测试通过。
2. **收尾双验证**（项目纪律）：批量改动后必跑 `wc -l` + 关键词命中数验证，不凭"调用了 Edit"报完成。
3. **接口变更固定动作**：REST 变更 → `npm run gen:api` → 看 TS 报错修调用点；WS/MCP 变更 → 更新 surface 红线测试。
4. **每里程碑出口**：`pytest` 全绿 + `ruff` 0 错 + 冒烟（62 skill 真实数据）+ 本计划该表全部任务勾销。
5. **文档同步**（RK-V2-06）：实现与 `docs/12` 偏差 → 当日回写 `docs/12`；需求变更 → 回写 `docs/11` 并留痕；两文档不动 `docs/00`（Q-06 决议）。
6. **依赖冻结**：本期不新增第三方依赖（V2-T8 纪律）；确需引入先对账 `docs/02` §9。
